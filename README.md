## 📌 Project Overview

This project analyzes Swiggy restaurant data to uncover insights into restaurant availability, pricing, ratings, cuisine preferences, and city-wise food trends. The objective is to transform raw restaurant data into actionable business insights using data cleaning, exploratory data analysis (EDA), and interactive visualizations.

The project demonstrates an end-to-end analytics workflow, from data preprocessing to dashboard creation.

---

## 🎯 Business Problem

Food delivery platforms like Swiggy host thousands of restaurants across multiple cities. Understanding customer preferences and restaurant performance is essential for:

- Improving customer experience
- Identifying high-performing cuisines
- Optimizing pricing strategies
- Understanding city-wise demand
- Supporting restaurant expansion decisions

This project answers these business questions through data analysis.

---

## 📊 Business Questions Answered

- Which cities have the highest number of restaurants?
- Which cuisines are the most popular?
- Which restaurants have the highest ratings?
- How are restaurant ratings distributed?
- What is the average cost across cities?
- Which cities are the most expensive?
- Which cuisines dominate each city?
- How does price relate to ratings?
- What percentage of restaurants are highly rated?
- Which restaurants provide the best value for money?

## 📈 Key Insights

- Restaurants are heavily concentrated in metropolitan cities.
- A small number of cuisines account for most restaurant listings.
- Higher pricing does not always correspond to higher customer ratings.
- Most restaurants fall within the mid-price range.
- Several restaurants maintain excellent ratings while offering affordable pricing.
- Customer ratings are generally concentrated between 4.0 and 4.5.
- Premium restaurants represent a relatively small portion of the overall market.
